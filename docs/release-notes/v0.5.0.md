# SiftBar 0.5.0

This release is a redesign of the dashboard and of the scanning experience.

- **A clearer dashboard.** Grouped sidebar (Review / Storage / System), a risk
  rail on every row, humanized paths (`~/Library/Caches/...`), compact rows
  without repeated boilerplate, and at most four key numbers per page.
- **Scanning you can see and stop.** A first scan shows a full workspace with
  the four steps, live progress and elapsed time. A rescan (or the refresh
  right after an action) shows a banner over the previous results, and the
  background disk map uses a thin progress line without locking the list.
  **Stop** cancels the scan and its running `du` processes immediately.
- **Instant feedback after actions.** Succeeded items leave every view at once;
  the list refreshes in seconds and the space map catches up in the background.
  Deleted paths are tombstoned briefly, so a scan that raced the Trash move
  cannot bring an item back.
- **Safer confirmation.** Return no longer triggers a destructive action; only
  the explicit button runs it.
- **Better failure handling.** The result card explains why items failed and
  can retry just those items.
- **Menu bar** shows the icon only; counts stay in the popover.
- **Fixes.** The status line no longer says "Nothing has been changed" right
  after a change; the Finder button appears on hover; the result card can open
  the Trash.
