# SiftBar 0.6.0

This release makes the first run calmer and the Full Disk Access step finish
the job on its own.

- **A guided first run.** The empty state is now a centered start screen: what
  SiftBar inspects, the Analyze → Review → Apply loop and the current access
  status, with a single button to start. No second call to action above it.
- **Full Disk Access that actually restarts.** Granting access now ends with
  **Restart & Check Access**: SiftBar closes, reopens and verifies the
  permission itself. The old “Check again” button is gone, and **Choose
  Folders Instead…** stays a visible alternative.
- **Faster scans.** Measured sizes are cached between scans (10 minutes,
  invalidated when a folder changes), folder walks run with bounded
  concurrency, and `/Library/Developer` is skipped — so machines with Xcode no
  longer spend 30–40 s on the disk map.
- **Sturdier actions.** Before quitting a process, SiftBar re-confirms the PID
  still belongs to it, and Trash targets are re-validated right before moving
  them.
- **Fewer hangs.** A stuck command is now killed after a grace period instead
  of blocking the scan or Stop, and one failing system probe no longer blanks
  the whole report.
- **Menu bar dot is back**, and the risk label now lines up with the impact
  value.
- **Universal app.** The download runs natively on Apple Silicon and Intel
  Macs.
- **Small fixes.** History is written off the main thread and its file is
  private to you; the “System & other” row now explains where Xcode simulator
  bytes are counted.
